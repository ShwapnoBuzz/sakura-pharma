এই ফোল্ডারে ওষুধের ডেটা ফাইল রাখা হয় না (পাবলিক কোড)। / The medicine data file is NOT included here (public code only).
সফটওয়্যারে: সেটিংস → "সম্পূর্ণ বাংলাদেশ ওষুধ ডাটাবেস লোড করুন" → আপনার কম্পিউটারে রাখা bd_medicines.json (বা bd_medicines.js) ফাইলটি বেছে নিন।
In the app: Settings → "Load full Bangladesh medicine database" → choose bd_medicines.json (or bd_medicines.js) from your computer.
For a local-only build you may place bd_medicines.js in this folder; it is ignored by git (.gitignore).
